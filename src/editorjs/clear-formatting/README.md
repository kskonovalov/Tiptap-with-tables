# ClearFormatting — inline-инструмент для EditorJS

Добавляет в inline toolbar кнопку **«Очистить форматирование»**, которая
появляется при выделении текста и снимает всё inline-форматирование
(жирный, курсив, ссылки и т.п.) с выделенного фрагмента.

Плагин самодостаточный — его нужно **скопировать в проект с EditorJS**
(в этом репозитории EditorJS не установлен, код лежит здесь как reference).

## Состав

- `index.js` — сам инструмент (реализует inline-tool API EditorJS)
- `utils/selection.js` — работа с `window.getSelection()`: проверка наличия
  форматирования и его снятие
- `index.css` — стили состояния кнопки

## Подключение

```js
import ClearFormatting from './clear-formatting';

const editor = new EditorJS({
  tools: {
    clearFormatting: {
      class: ClearFormatting,
      // опционально:
      config: {
        shortcut: 'CMD+SHIFT+C', // горячая клавиша (по умолчанию нет)
        closeOnClick: false,     // закрывать ли inline toolbar после клика
      },
    },
  },
});
```

## Конфигурация

| Параметр       | Тип       | По умолчанию | Описание                                          |
|----------------|-----------|--------------|---------------------------------------------------|
| `shortcut`     | `string`  | `null`       | Горячая клавиша для вызова инструмента             |
| `closeOnClick` | `boolean` | `false`      | Закрывать inline toolbar сразу после нажатия      |
| `icon`         | `string`  | SVG          | HTML-иконка кнопки                                 |

## Локализация

Подпись и тултип берутся через `api.i18n.t()`, ключ — `clearFormatting`
(по умолчанию «Очистить форматирование»). При необходимости переопределяется
через словарь i18n EditorJS.

## Ограничения (TODO)

- **Частичное** выделение внутри одного inline-тега снимается не полностью:
  очистка `on this` в `some <b>emphasis on this text</b>` пока оставляет текст
  внутри `<b>`. Полное выделение содержимого тега (в т.ч. заголовка) очищается
  корректно. См. комментарии в `utils/selection.ts`.
