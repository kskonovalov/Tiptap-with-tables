# Горячие клавиши

> **Ctrl** — для Windows и Linux &nbsp;|&nbsp; **Cmd (⌘)** — для macOS

---

## Общие действия

| Windows / Linux | macOS | Действие |
|---|---|---|
| `Ctrl + Z` | `Cmd + Z` | Отменить действие |
| `Ctrl + Shift + Z` | `Cmd + Shift + Z` | Повторить действие |

---

## Форматирование текста

| Windows / Linux | macOS | Действие |
|---|---|---|
| `Ctrl + B` | `Cmd + B` | Жирный |
| `Ctrl + I` | `Cmd + I` | Курсив |
| `Ctrl + U` | `Cmd + U` | Подчёркнутый |
| `Shift + Enter` | `Shift + Enter` | Новая строка (без нового абзаца) |
| `Ctrl + Shift + S` | `Cmd + Shift + S` | Зачёркнутый |
| `Ctrl + E` | `Cmd + E` | Встроенный код |
| `Ctrl + Shift + H` | `Cmd + Shift + H` | Выделение цветом |

---

## Списки

| Windows / Linux | macOS | Действие |
|---|---|---|
| `Ctrl + Shift + 7` | `Cmd + Shift + 7` | Нумерованный список |
| `Ctrl + Shift + 8` | `Cmd + Shift + 8` | Маркированный список |
| `Ctrl + Shift + 9` | `Cmd + Shift + 9` | Список задач |
| `Tab` | `Tab` | Увеличить отступ элемента списка |
| `Shift + Tab` | `Shift + Tab` | Уменьшить отступ элемента списка |

---

## Выравнивание текста

| Windows / Linux | macOS | Действие |
|---|---|---|
| `Ctrl + Shift + L` | `Cmd + Shift + L` | По левому краю |
| `Ctrl + Shift + E` | `Cmd + Shift + E` | По центру |
| `Ctrl + Shift + R` | `Cmd + Shift + R` | По правому краю |
| `Ctrl + Shift + J` | `Cmd + Shift + J` | По ширине |

---

## Блоки

| Windows / Linux | macOS | Действие |
|---|---|---|
| `Ctrl + Shift + B` | `Cmd + Shift + B` | Цитата |
| `Ctrl + Alt + C` | `Cmd + Alt + C` | Блок кода |
| `Ctrl + Shift + A` | `Cmd + Shift + A` | Блок уведомления |

---

## Медиа и ссылки

| Windows / Linux | macOS | Действие |
|---|---|---|
| `Ctrl + Shift + I` | `Cmd + Shift + I` | Вставить изображение |
| `Ctrl + Click` | `Cmd + Click` | Открыть ссылку в новой вкладке |

---

## Навигация внутри блоков

| Клавиша | Действие |
|---|---|
| `Tab` | Переход между полями блока (если возможно, например, у таблиц) |
| `Enter` | Открыть диалог загрузки файла (когда выбран блок загрузки изображения) |
